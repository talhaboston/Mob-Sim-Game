MOB SIM GAME

**Created by Talha Yesilyurt**

A 2D survival game built with **Python and Pygame**. Choose a difficulty, fight enemies with your sword, collect potions, and try to survive as long as possible.

## 🎮 Controls

* **W / A / S / D** — Move
* **Arrow Keys** — Move
* **Mouse** — Control the sword

## ⚔️ Features

* Four difficulty levels: Easy, Medium, Hard, and Impossible
* Sword combat
* Mouse-controlled sword
* Enemy movement and collision detection
* Score system
* Lives system
* Healing potions
* Multiple backgrounds
* Optional hitbox display
* Increasing difficulty as your score increases

## 🎯 How to Play

Choose a difficulty from the main menu.

Defeat enemies with your sword to increase your score. Avoid enemies because they reduce your lives when they touch you.

Potions can restore lives.

The game becomes more challenging as your score increases.

## 🛠️ Built With

* Python
* Pygame

## ▶️ How to Run

Install Pygame:

```bash
pip install pygame
```

Then run:

```bash
python main.py
```

Make sure the `assets` folder stays in the same directory as `main.py`.
